# Tixo Connect 🇸🇪

Страница импорта VPN-ключей Tixo в приложения Happ и INCY.

Кнопки Telegram-бота открывают страницу, которая передаёт ключ выбранному приложению на телефоне или компьютере. Если автоматический переход не сработал, можно нажать кнопку открытия или скопировать ключ для ручного импорта.

Приложение должно быть установлено. После импорта нужно подтвердить добавление профиля и включить VPN.

Ключ передаётся во фрагменте URL после `#` и обрабатывается в браузере. Страница не отправляет его на сервер и не использует аналитику.

Страница размещается на GitHub Pages. VPN-сервер Tixo расположен в Стокгольме, Швеция.
